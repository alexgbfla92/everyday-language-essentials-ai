# Continue por aqui

Este repositório está em planejamento. O [README público](README.md) descreve a experiência que queremos oferecer à comunidade. A primeira sessão no Codex serve para revisar a arquitetura e decidir como testar essa experiência.

1. Extraia o conteúdo na raiz do clone. README.md, AGENTS.md e este arquivo devem aparecer lado a lado. O README público ocupa o lugar do título provisório do clone.
2. Abra a pasta no Codex e use o [primeiro prompt](FIRST-PROMPT.md).
3. Leia a [arquitetura](docs/ARQUITETURA.md), o [contrato pedagógico](docs/METODOLOGIA.md), as [regras de persistência](docs/PERSISTENCIA.md) e o [plano de validação e distribuição](docs/VALIDACAO-E-ROADMAP.md).

## Origem desta edição

O README foi copiado do manifesto avulso fornecido pelo autor. Os demais arquivos foram escritos para esta transição com base na conversa de planejamento. Os testes de instalação, aula e retomada descritos são propostas para o beta.
