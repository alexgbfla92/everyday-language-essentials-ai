# Orientações para trabalhar neste repositório

O README da raiz é o manifesto público do produto. A skill fica inteira em skills/everylang/ e só referencia arquivos dessa pasta; manifestos de plataforma ficam na raiz. Mantenha a documentação de desenvolvimento em docs/. Todo PR sobe o VERSION com tools/bump_version.py. Consulte START-HERE.md para localizar as decisões de projeto.

A primeira atividade é uma revisão de arquitetura, sem implementação. Distinga decisões do autor, propostas de implementação e capacidades comprovadas em testes. Use dados fictícios nas demonstrações. Mantenha arquivos de alunos, credenciais, links de pastas pessoais e backups fora do Git. EnglishMission e EverydayEssentials são projetos independentes e suas referências são somente leitura.
