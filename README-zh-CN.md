# TalkGo

[English](README.md) · [Português (Brasil)](README-pt-BR.md) · [Español](README-es.md) · [Français](README-fr.md) · [Deutsch](README-de.md) · **简体中文**

## 学你真正需要的语言，去经历对你重要的事。

**还没准备好就开口。说错、提问、再试一次。重要的是不停止交流。**

**TalkGo** 是一个**公开、开源的 skill**，以真实情境为导向学习语言，作为一种实用、可定制的方法分享给社区。它不要求你先学完整套课程再开口，而是帮助你为**生活中真正重要的经历**做准备：用你选择的语言、节奏和期限。

求助、认识新朋友、参加活动或应对突发情况，并不需要掌握所有语法规则。你需要的是练习、有用的表达和尝试的勇气。练习就从这里开始。

我们的目的不是卖课程，也不是把学习者当成客户，而是与社区分享一个开放的工具，尝试另一种学习方式：有自己的目标、允许犯错、不断有机会对话。

## 这种方法有什么不同？

传统课程通常按级别、语法单元和考试来组织学习。对于追求全面学习、证书或学术水平的人来说，这很有价值。TalkGo 从另一个问题出发：

> **你真正需要用这门语言做到什么？**

答案决定你的任务（mission）。重点不是承诺在神奇的期限内完全流利，而是培养**在具体情境中的沟通自主能力**，通过口语练习、重复和反馈来实现。

### 一门语言很庞大。你的下一次对话不必如此。

英语、葡萄牙语、西班牙语等语言的大型词典收录了**数十万个词条**，详细的语法书根据计算方式可能包含数百条规则和子规则。把这些全部学会是一个长期工程。**为一次具体的对话做准备，则是一个范围小得多的目标。**

以下只是**示意，而非科学标准或效果保证**：掌握约 **100 个常用词**，可以尝试打招呼、提出请求和表达基本需求；**200 到 500 个**，可以借助语境进行更多简单交流；**500 到 1,000 个**，可以开始就熟悉的话题进行有限的对话；**2,000 个以上的高频词**，通常能更好地应对日常情境。实际效果取决于听力、词语搭配、语境、对话对象和练习，而不仅仅是词汇量。

所以问题不是"离掌握整门语言还差多少？"，而是**"为了在下一次经历中被理解，我需要练习哪些词语、句子和情境？"**

| 传统教学（多种形式） | TalkGo |
| --- | --- |
| 按级别和主题预先设定的课程 | 根据学习者目标构建的任务 |
| 语法常常先于应用 | 先沟通，需要时再讲解 |
| 练习可能偏重读和写 | 以情景模拟和口语练习为核心 |
| 错误常被视为需要避免的事 | 错误被视为训练的自然部分 |
| 许多学生学习相同的主题顺序 | 情景、优先级和时长都可调整 |
| 进步以完成的内容来衡量 | 进步以能够沟通的内容来衡量 |

## 你的生活决定内容，而不是反过来。

想象一下 90 天后去迪士尼旅行。你的任务可以集中在乐园、餐厅、酒店、购物和突发情况中的交流。如果你不需要经过机场，就不必练习这个话题。

再想象一位参加教会活动、要去西班牙参加大会的人。他可以优先练习自我介绍、会后交谈、集体用餐、询问信息和社交互动，用西班牙语，结合那个场合的词汇和情境。

婚礼、洗礼、会议、探亲、工作会议或任何其他活动也是如此。**不是你去适应固定的课程，而是练习去适应你的任务。**

## 开口说。即使说错。

在 TalkGo 中，你不必等到能说出完美的句子。

- **只会一部分？** 就说那一部分。
- **忘了某个词？** 用你会的词来解释。
- **卡住了？** 暂时把母语和正在学的语言混着说，然后请求帮助。
- **不会用过去时、现在时或将来时？** 提问，听一个例子，再试一次。
- **说错了？** 得到有用的纠正，换种说法，继续对话。

原则很简单：**尝试先于完美**。

TalkGo 帮助你把不完整的句子变成越来越清楚、自然的表达。纠正不应该打断每一个词，也不应该把每次对话都变成考试。它的存在是为了帮助你继续前进。

## 在这里，你不必为犯错感到难为情

对很多人来说，学语言最大的障碍不是词汇不足，而是难为情：害怕发音错误、忘词、混淆时态，或在别人面前显得笨拙。这种障碍会出现在私教课、班级、网上交流，甚至朋友和家人之间。

TalkGo 提供了一个有力的选择：**一个由人工智能陪练、没有社交压力的练习空间**。你面前没有观众、同学，也没有会嘲笑你口音的人。AI 无意羞辱、歧视或嘲弄你。它的职责是帮助你练习、理解、纠正，然后再试一次。

**错一次。错一百次。需要的话，错一千次。你可以一直尝试下去。**

借助 AI，你可以：

- **通过语音或文字对话**（取决于可用功能），练习日常生活中的情境。
- **按编号查询任何句子**：目标语言中的每个句子都有唯一编号（"重复第 132 句"、"解释第 145 段对话"）。
- **暂停和继续，不丢失任何内容**，语音模式下也可以。
- **每种语言可以有多个任务**（例如在某个日期前"为伦敦之行做准备"，情境包括机场、入境、公共交通和餐厅），用 `New-Mission` 和 `Set-Mission` 创建和调整，并用 `Start-Practice` 开始所选任务的下一次练习。
- **不必会整句也能开口：** 先用目标语言开头，用母语补上一部分，再请求帮助完成其余部分。
- **毫无顾虑地提问：** 句子怎么组织、为什么用这个词，或者怎样用过去时、现在时、将来时表达同一个意思。
- **请求纠正和例子**，而不把每个错误都变成打断或评分。
- **想重复多少次就重复多少次：** 一个词、一句话或整段对话。
- **控制节奏：** 根据你的理解程度，请它说慢一点、再慢一点或快一点。
- **重新开始同一个模拟**，直到你对自己的回答更有把握。

句子不完整、发音奇怪、忘了学过的内容，都没关系。**你不需要让 AI 刮目相看，只需要允许自己练习。**

人工智能无法替代与真人交谈的所有体验，它的纠正也可能出错。但它可以成为一个随时可用的陪练伙伴，帮你重复、解释、调整练习，而没有那种常常让我们沉默的社交压力。

> **难为情不必是练习的一部分。错误可以成为进步的一部分。**

## 通过熟悉、语境和重复来学习

许多结构之所以变得熟悉，是因为我们一遍又一遍地听到和使用它们：在对话、歌曲、视频、剧集或模拟中。

这正是这个 skill 想要培养的熟悉感。你听到一种自然的说法，尝试使用，得到反馈，然后在新的情境中再次遇到它。渐渐地，表达和句型会越来越不费力地说出来。

语法仍然是一种工具：如果关于某个时态或语序的简短讲解能让你开口，那就欢迎。**但记住大量规则既不是起点，也不是核心目标。**

## 你的起点：一次快速、没有压力的诊断

在开始任务之前，skill 会建议在所选语言中进行一次**简短的诊断**。这不是决定及格与否的考试，而是一次初步对话，用来了解你当前的水平，找出**优势、困难和改进空间**，并让接下来的活动符合你的真实需要。

**零基础？没关系。** 只回答你能理解的部分。需要时可以说母语、提问、请 AI 重复或解释。试着说出一个词、补全一个表达，或用想学的语言组成一句话，即使说错也没关系。这些尝试同样有助于找到最合适的起点。

诊断不是要求你已经会说，而是为了**找到帮助你起步的方法**。

## 你的进步清晰可见，并且可以重新评估

**你可以随时请求一份进度报告**，根据你学习历程中的记录，了解已经练习过的内容、在哪些方面更有信心，以及哪些情境或结构还需要加强。

你也可以不时请求**一次新的诊断**。把结果与起点进行比较，可以帮助你看到自己的进步，并调整接下来任务的重点。目的不是收集分数，而是越来越清楚地看到**你已经能够沟通什么**。

## Entertainment Lab：学习也可以很有趣

每次练习的最后一个阶段是 **Entertainment Lab** 的轻松时刻：你观看一段与刚才练习内容相关的**简短 YouTube 视频，可能是一个故事或一首歌**（最长为练习时长的四分之一：30 分钟练习中为 7 分半），并回答几个理解问题。它是练习的一部分：完成它之后练习才算完成。如果有**母语和目标语言的字幕**，可以借助它们在更自然的语境中识别词语、表达和结构。

这不是又一次考试，也不是一份练习清单。这是在模拟之外聆听这门语言的机会，留意句子在真实情境中如何出现，还能在快乐中结束练习。视频的选择和字幕的可用性取决于平台上可访问的内容和功能。

## 简短的任务，为你量身设置

每个人都可以决定要练习什么，并根据自己的需要调整体验：

- **语言和场合：** 旅行用英语、开会用西班牙语，或其他沟通目标。
- **任务和期限：** 为几周或几个月后的活动做准备。
- **优先情境：** 练习有用的内容，省略不适用的内容。
- **练习时长：** 根据日程选择短一些或长一些的练习。
- **练习重点：** 对话、听力、实用句子和情景模拟。
- **节奏和支持：** 请求例子、重复、获得纠正，并回到难点。
- **你的母语：** 所有讲解、消息以及你的 Central 中的内容都使用你的母语。

体验以你需要做到的事为导向，而不是一份与你的现实脱节的必修主题清单。

## 任务是如何进行的？

**开始之前：先做初始诊断。** 一次简短的对话有助于让任务适合你的水平，即使你还不能说完整的句子。

**1. 描述你的经历。** 说说你要去哪里、打算做什么、需要和谁交谈，以及有多少准备时间。

**2. 选择重要的内容。** 选出可能遇到的情境、沟通目标和可用于练习的时间。

**3. 进入场景。** 练习对话和情景模拟。尝试用目标语言回答，即使不能完全说对。

**4. 获得帮助，再试一次。** 学习实用表达，调整你的句子，反复练习直到熟悉。

**5. 把所学带进生活。** 在真实交流中使用你练过的内容；有新的需要时，开始另一个任务。

**一路上：** 随时请求进度报告，定期重新评估，并在练习结束时享受 Entertainment Lab，轻松巩固所学。

## 流利不是承诺，沟通才是目的。

TalkGo 不承诺你会在 30、60 或 90 天内变得流利，也不承诺你不再犯错或没有口音。目标更加具体：**帮助你在决定要准备的情境中更好地沟通**。

一个简短的任务可以增强你在特定场合中的信心。随着时间积累，多个任务可以建立越来越丰富的表达储备，并帮助你达到有意义的水平。这种进步取决于练习频率、接触语言的程度以及每个人的特点。

不必等到流利才开始交谈。而开始交谈，可能正是走向流利的途径之一。

## TalkGo 适合谁？

适合已经订好旅行、有重要会面、有工作机会、要参加社交活动，或者只是有一个具体理由要说另一种语言的人，他们不想等到觉得掌握了整门语言才去经历这些。

尤其适合能听懂一些词但组织句子时会卡住的人；害怕因为犯错而被评判的人；以及更喜欢通过练习对自己有意义的情境来学习的人。

## 一个向社区开放的 skill

TalkGo 是一个**开源**项目，供社区使用、改编和改进。每个人选择自己的任务和想练习的内容；目的不是强加单一的学习路径，而是让语言练习更容易获得、更贴近情境、更少压力。语音、文字及其他功能是否可用，取决于你使用的 AI 平台。

## 如何安装

TalkGo 通过浏览器用一个 .zip 文件安装到 Claude 和 ChatGPT。这样安装后，它会保留在你的账户中，并出现在你所有的设备上：网页、桌面应用和手机。

### 1. 下载插件

下载最新版本：**[talkgo-plugin.zip](https://github.com/alexgbfla92/everyday-language-essentials-ai/releases/latest/download/talkgo-plugin.zip)**。以前的版本以及每个版本的变化见 [Releases](https://github.com/alexgbfla92/everyday-language-essentials-ai/releases)。

不要解压该文件：同一个 .zip 适用于 Claude 和 ChatGPT。

### 2. 在 Claude 中安装

1. 在浏览器中打开 [claude.ai](https://claude.ai)，进入 **设置 → 自定义 → 插件**（Settings → Customize → Plugins）。
2. 点击 **添加 → 上传插件**（Add → Upload plugin），选择 `talkgo-plugin.zip`。
3. 在 **设置 → 自定义 → 连接器**（Connectors）中，开启 **Google Drive**、**Google Docs** 和 **Google Sheets**（你的 Central 位于 Google Drive）。
4. 建议：在 **设置 → 功能**（Capabilities）中允许域名 `youtube.com`、`www.youtube.com`、`m.youtube.com` 和 `youtu.be`。这样 Entertainment Lab 可以在 YouTube 页面上确认视频的标题、频道和时长；否则只能使用搜索结果中显示了时长的视频。
5. 在新对话中输入 `/talkgo` 并选择该 skill（例如 `/talkgo Start`）。

### 3. 在 ChatGPT 中安装

1. 在浏览器中打开 [chatgpt.com](https://chatgpt.com)，点击侧边栏中的 **插件**（Plugins）。
2. 点击 **添加**（Add），选择 `talkgo-plugin.zip`，然后点击 **添加插件**（Add plugin）确认。
3. 连接 **Google Drive** 应用，并授予创建和编辑文件的权限（Central 使用 Google Docs 和 Sheets）。
4. 在对话中保持网页搜索可用，以便 Entertainment Lab 找到 YouTube 视频。
5. 在新对话中用 `@TalkGo` 调用（例如 `@TalkGo Start`）。`$talkgo:talkgo` 也可以。

### 首次使用：Start

发送 `Start`。一个简短的向导会一次一个问题地引导你：

1. **你的母语。** TalkGo 会在所有消息、`Help` 的说明以及你的 Central 的内容中使用它。如果你的第一条消息看不出你说哪种语言，问题会用英语、西班牙语、葡萄牙语和法语提出。
2. **你的 Central：** 一个属于你自己的文件夹（推荐 Google Drive），保存诊断、任务、练习和进度，让任何对话、任何设备都能从上次停下的地方继续。
3. **你想练习的语言：** 从美式英语、西班牙语、法语、巴西葡萄牙语、普通话（中文）、意大利语、日语、德语、韩语、印地语和阿拉伯语中选择一种或多种。
4. **一次简短的水平诊断。**
5. **你的第一个任务**，包括目标日期和情境。
6. **你的第一次练习**，已经准备好。
7. **如何组织项目和对话**，包括建议的名称和每个对话要发送的命令。

你可以随时再次运行 `Start`：它会从上次停下的地方继续。`Help` 会显示已安装的版本（例如"TalkGo v0.21.0"）、默认上下文和所有命令。第一次对话可直接使用的消息见 [FIRST-PROMPT.md](FIRST-PROMPT.md)。

### 你的母语

命令始终使用英语，格式为 `Verb-Entity`（动词-对象）：`Get` 显示，`New` 创建，`Set` 修改，`Remove` 删除，`Start`/`Pause`/`Resume`/`Finish` 控制练习。其他一切都使用你的母语：消息、讲解、反馈，以及 `Help` 中的说明和示例。Central 的文件夹和文件名称目前提供英语、葡萄牙语（巴西）、西班牙语、法语和德语版本；母语为中文时，文件夹和文件名称为英语（例如 `Missions` 和 `Practices`），其余一切仍使用中文。

`Start` 之后的基本流程：

| 步骤 | 命令 |
| --- | --- |
| 初始设置（向导） | `Start` |
| 进行某种语言的诊断 | `Start-Diagnostic English` |
| 创建任务（标题、描述、目标日期和情境） | `New-Mission English` |
| 练习 | `Start-Practice` |
| 按任务和状态查看练习 | `Get-Practices` |
| 查看进度 | `Get-Progress` |

如果你没有指定 Central、语言或任务，而可选项不止一个，TalkGo 会询问你，并推荐默认选项；要更改默认值，请使用 `Set-Default central|language|mission`。你也可以用自己的话提出请求（"我想练习英语"、"我做过哪些练习？"）。

### 用项目组织，每次练习一个对话

我们建议始终在 AI 工具的**项目**中使用 TalkGo（Claude 和 ChatGPT 都支持创建项目）。在 `Start` 结束时，TalkGo 会根据你的真实数据建议名称：

- **为每个任务创建一个项目**，取一个与任务相关的简短名称。例如：旅行任务用 `English-Travel` 项目，工作会议用 `English-Meeting` 项目。
- **在项目中保留一个"进度"对话**，用于跟进和管理：`Get-Progress`、`Get-Practices`、`Get-Missions`、`Set-Mission`。
- **每次练习新开一个对话**，并以练习命名。例如在 `English-Travel` 项目中：`Practice-0001-Airport check-in`、`Practice-0002-Immigration`、`Practice-0003-Public transport`，依此类推。准备练习时，TalkGo 会建议对话名称和要发送的第一个命令。
- **重命名对话：** 在 Claude 中，点击顶部的对话标题（或侧边栏中对话旁的 **…**）→ **重命名**（Rename）；在 ChatGPT 中，点击侧边栏中对话旁的 **…** → **重命名**，并用 **移至项目**（Move to project）把它放进项目。

这样每个对话都简短而专注，很容易回到某次具体的练习，每个任务的历史也集中在一个地方。连接各个对话的是你的 Central：项目中的任何对话都能从上次停下的地方继续。

### 更新

通过文件上传的插件不会自动更新。当 [Releases](https://github.com/alexgbfla92/everyday-language-essentials-ai/releases) 中发布新版本时：

1. 通过同一个链接重新下载 `talkgo-plugin.zip`。
2. 在 Claude 和 ChatGPT 中删除已安装的 TalkGo 插件，然后像安装时一样上传新文件。
3. 打开一个新对话，用 `Help` 检查版本。
