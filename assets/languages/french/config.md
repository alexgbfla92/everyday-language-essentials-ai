# Configuration — français (France)
Langue cible : français de France (`fr-FR`). Langue des explications : portugais brésilien par défaut. Parcours : 90 jours, séances : 20 minutes, réévaluation : tous les 14 jours ; personnalisables. Ce parcours possède son propre diagnostic, ses propres séances et son propre suivi. Les consignes de simulation, les dialogues et les retours linguistiques doivent utiliser un français naturel, sans traduire littéralement l’anglais. Préférer « vous » dans les contextes professionnels et avec des inconnus ; expliquer « tu » selon le contexte. Travailler les liaisons, les voyelles nasales, les sons /y/ et /u/, l’élision et l’intonation, sans prétendre juger une prononciation à partir d’une transcription. Introduire les structures grammaticales utiles à la tâche, pas une liste fixe de temps anglais. Les consignes de soutien peuvent être en portugais.
