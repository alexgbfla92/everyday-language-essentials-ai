# Initial diagnostic roadmap — Korean (South Korea) (ko-KR)

Default length: 30 minutes, customizable. Before starting, create the diagnostic record (ID, language, regular/test type, `include_in_metrics`, status). Run all stages in one go, without pauses: each stage change saves a silent checkpoint and goes straight on to the next stage in the same message (SKILL.md, Diagnostic saving). Never confuse planned minutes with observed minutes. Instructions and feedback in the learner's native language; tasks in Korean.

1. Opening: ask in Korean (with support in the native language for beginners) what the learner needs the language for and confirm the variety (standard Korean (Seoul) by default).
2. Listening (8 min): short spoken announcements, such as «12번 게이트에서 탑승을 시작합니다» (Sibi-beon geiteu-eseo tapseung-eul sijakhamnida) or a hotel message. One question at a time. Without real audio, record “listening not assessed”; never replace it silently with reading.
3. Speaking and interaction (10 min): introductions, asking for help, explaining a problem, then a realistic surprise («예약을 찾을 수 없습니다» (Yeyak-eul chajeul su eopseumnida)).
4. Reading (7 min): an everyday notice and a short work message when relevant; ask for meaning and next action.
5. Feedback (5 min): provisional CEFR by skill, observed evidence, confidence, limitations, priorities and next mission. Never infer pronunciation from a text transcript.

At the end, save and reread the diagnostic record, the progress log and the language state. If writing does not work, hand over a copyable checkpoint and say it was not saved. A test record never counts in the metrics.
