# Initial diagnostic roadmap — Brazilian Portuguese (pt-BR)

Default length: 30 minutes, customizable. Before starting, create the diagnostic record (ID, language, regular/test type, `include_in_metrics`, status). Run all stages in one go, without pauses: each stage change saves a silent checkpoint and goes straight on to the next stage in the same message (SKILL.md, Diagnostic saving). Never confuse planned minutes with observed minutes. Instructions and feedback in the learner's native language; tasks in Portuguese.

1. Opening: ask in Portuguese (with support in the native language for beginners) what the learner needs the language for and confirm the variety (Brazil by default).
2. Listening (8 min): short spoken announcements, such as «O voo para Recife está atrasado» or a hotel message. One question at a time. Without real audio, record “listening not assessed”; never replace it silently with reading.
3. Speaking and interaction (10 min): introductions, asking for help, explaining a problem, then a realistic surprise («Não encontramos a sua reserva»).
4. Reading (7 min): an everyday notice and a short work message when relevant; ask for meaning and next action.
5. Feedback (5 min): provisional CEFR by skill, observed evidence, confidence, limitations, priorities and next mission. Never infer pronunciation from a text transcript.

At the end, save and reread the diagnostic record, the progress log and the language state. If writing does not work, hand over a copyable checkpoint and say it was not saved. A test record never counts in the metrics.
