# Defaults — TalkGo

- `default_language: en-US`; `enabled_languages: [en-US, es-ES, fr-FR, pt-BR, zh-CN, it-IT, ja-JP, de-DE, ko-KR, hi-IN, ar]` (the supported target languages; the learner's choice is `chosen_languages`). Every message, folder, file and record uses the learner's native language (`native_language` in the central state); commands stay in English.
- Mission: title, description (scenario and context), situations and target date set by the learner (the target date is required); default regular practice: 30 minutes, never more than 35, the Entertainment Lab included; initial diagnostic: 30 minutes; review every 14 days.
- Initial priorities: 50% professional communication/meetings and 50% everyday life/travel, customizable.
- Default practice in seven stages (30 minutes): Mission Briefing 3 min; guided drill/review 4 min; realistic simulation 7 min; unexpected event 4 min; feedback 2 min; closing (recap, phrases and next step) 1 min; Entertainment Lab 9 min, with a video whose whole verified duration is at most 25% of the practice (7 min 30 s in 30 minutes), prepared when the practice is created. Each stage has a saved state (pending, in progress, completed); the practice is completed only after stage 7. The current stage is always shown to the learner. In the first practice, never invent a previous review.
- One question at a time in simulations. Do not interrupt for minor mistakes. Use natural target language in the simulation and the native language for support when appropriate.
- The learner chooses the mission target date (from tomorrow to months ahead), practices of 5, 10, 15, 20, 30 or 35 minutes (or another length up to 35), specific goals, pace, modality, accent/variety and mix of scenarios.
- Customization never deletes history, changes CEFR without evidence or turns planned minutes into actual duration. Record overrides in the language and in the session. Duration changes redistribute the blocks proportionally, keeping preparation, practice, unexpected event and feedback; in very short practices, simplify the scenario.
- Each language has independent missions, diagnostic, progress, review and sessions. The learner's explicit choice wins; with no choice, use the default language.
- Tests never count in learning metrics, including missions with a close target date.
