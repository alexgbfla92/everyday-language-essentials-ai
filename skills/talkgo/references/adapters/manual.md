# Adapter: manual mode

Use this mode when the session cannot write and reread the learner's files, for example in a chat with no write-capable connector and no connected folder. The files and layout are the same as in the other adapters; the learner does the writing.

## Set up

Explain in one sentence, in the learner's native language, what is missing to save automatically (a Drive connector with write access or a connected folder). If the learner wants to continue anyway, offer the `talkgo.json` and the templates of the native language (`assets/locales/<code>/templates/`) for the learner to create the structure in their own folder. Record `storage: manual` in the central state handed over.

## During the activity

At each resume point, hand over a copyable checkpoint with the exact stage, the last confirmed ID and revision, the new phrases with their F and D numbers, the evidence and the next question. Make it clear that nothing is saved until the learner pastes the content into the given file.

## Resume

Ask the learner to attach or paste the session file and the language state. Use the revision and next question of the file, not the memory of the conversation. When automatic access returns, confirm the file in storage before announcing saved progress.
